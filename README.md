🤖 AI Learning Support Assistant

An AI-powered web application that helps students overcome learning difficulties by analyzing their learning problems, detecting emotions using Deep Learning models, and providing personalized learning guidance using Google Gemini AI. The system also maintains previous learning history and visualizes learning progress through an analytics dashboard.

📌 Project Overview

Traditional learning platforms provide the same explanation to every student without considering their emotional state. Students often struggle to understand difficult concepts, lack personalized support, and cannot easily track their learning progress.

The AI Learning Support Assistant solves this problem by allowing students to submit learning queries, automatically detecting emotions using BiLSTM and BERT models, generating personalized AI learning guidance through Google Gemini API, maintaining interaction history, and providing interactive analytics for continuous learning improvement.
